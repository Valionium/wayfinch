# Wayfinch

Wayfinch will be a free cycling web app: an offline co-pilot that answers questions at stops, by fixed rules on the phone.
It is not live yet. This repository holds its tools and checks so far.
Until it launches, today's bag planner, Load Check, stays at its address: https://load-check.valentin-hopstein.workers.dev

A weekly build of place data for ten countries lives in `pipeline/` (see `pipeline/README.md`). Its data is © OpenStreetMap contributors, under the ODbL licence.
